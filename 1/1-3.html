セキュリティ技術評価 - 3語（シラバス4.1）

脆弱性評估與安全性檢測
CVSS
しーぶいえすえす
通用脆弱性評分系統
Common Vulnerability Scoring System
ソフトウェアやシステムの脆弱性の深刻度を0から10の数値で客観的に評価し、対策の優先順位を決定するための共通基準。
客觀評估軟體或系統脆弱性嚴重程度（分數介於0到10）的共通標準，用以決定修復與處置的優先順序。
過去問（日本語） 考古題（中文）
CVSS（Common Vulnerability Scoring System）に関する記述として、最も適切なものはどれか。
ア. 脆弱性の深刻度を同一の基準で定量的に評価する仕組み。
イ. Webアプリケーションの脆弱性を自動で検出するツール。
ウ. ネットワーク上のパケットを監視して不正侵入を検知するシステム。
エ. 暗号化通信の安全性を評価するためのスコア。
正解：ア

【解析】CVSSは、情報システムの脆弱性に対する深刻度を共通の基準で定量的に評価するための標準的なスコアリングシステムです。
 關於 CVSS（Common Vulnerability Scoring System，通用脆弱性評分系統）的敘述，下列何者最恰當？
A. 以統一標準定量評估脆弱性嚴重程度的機制。
B. 自動檢測 Web 應用程式脆弱性的工具。
C. 監控網路封包以偵測非法入侵的系統。
D. 評估加密通訊安全性的分數。
正確答案：A

【解析】CVSS 是一種標準化的評分系統，旨在跨平臺以統一且客觀的標準定量評估資訊系統脆弱性的嚴重程度。
脆弱性診断
ぜいじゃくせいしんだん
弱點掃描／脆弱性診斷
Vulnerability Assessment
システムやネットワークのセキュリティ上の弱点を網羅的に検出・評価し、リスク低減の対策を講じるためのプロセス。
全面檢測並評估系統或網路中的安全弱點，提供基礎資訊以採取適當控制措施、降低風險的過程。
過去問（日本語） 考古題（中文）
脆弱性診断の目的として、最も適切なものはどれか。
ア. システムやネットワークに潜むセキュリティ上の弱点を網羅的に洗い出し、適切な対策を検討すること。
イ. 実際に攻撃を行ってシステムに侵入し、機密情報を奪取できるかを試すこと。
ウ. 社員のセキュリティ意識を向上させるための模擬訓練を行うこと。
エ. 障害発生時にシステムを迅速に復旧させるバックアップ計画を策定すること。
正解：ア

【解析】脆弱性診断は、システムの設定ミスや未修正のバグなどのセキュリティ上の弱点を網羅的に特定・評価することを目的とします。
 關於執行「脆弱性診斷（弱點掃描）」的主要目的，下列何者最恰當？
A. 全面排查系統與網路中潛在的安全弱點，以便檢討並實施適當的防護措施。
B. 實際發動攻擊嘗試侵入系統，驗證是否能成功竊取機密資料。
C. 進行模擬演練以提升員工的資訊安全意識。
D. 制定故障發生時能快速復原系統的備份計畫。
正確答案：A

【解析】脆弱性診斷（Vulnerability Assessment）著重於全面性的弱點清查與評估，選項 B 描述的則是滲透測試（Penetration Testing）。
ペネトレーションテスト
ぺねとれーしょんてすと
滲透測試
Penetration Testing
攻撃者の視点から実際の侵入を試みることで、システムのセキュリティ強度や防御力の有効性を検証するテスト。
從真實攻擊者的視角嘗試進行入侵，藉此驗證系統安全防護機制的有效性並找出潛在漏洞。
過去問（日本語） 考古題（中文）
ペネトレーションテストに関する記述として、最も適切なものはどれか。
ア. 実際の攻撃手法を用いてシステムに侵入を試み、セキュリティ上の弱点や侵入可能性を検証するテスト。
イ. システムの全プログラムコードを網羅的に監査してセキュリティ上のバグを発見する手法。
ウ. 脆弱性情報を公開する国際的なデータベース。
エ. アクセスログを分析して過去の不正アクセス履歴を調査する作業。
正解：ア

【解析】ペネトレーションテスト（侵入テスト）は、攻撃者の視点で実際に侵入を試み、防衛策の有効性や具体的なリスクを検証する手法です。
 關於「滲透測試（Penetration Testing）」的敘述，下列何者最恰當？
A. 採用真實的攻擊手法嘗試入侵系統，用以驗證安全弱點及被侵入的可能性。
B. 全面稽核系統的所有程式碼以發現安全 Bug 的手法。
C. 公開脆弱性資訊的國際資料庫。
D. 分析存取日誌以調查過去非法存取紀錄的作業。
正確答案：A

【解析】滲透測試（Penetration Testing）透過模擬真實駭客侵入手法，測試目標系統能否被穿透，並評估可能造成的實際損害。
