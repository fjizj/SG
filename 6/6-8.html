專案整體風險與個別風險
Overall and Individual Project Risks
プロジェクト全体に影響を与える不確実性（全体リスク）と、特定の作業や要素に起因する要因（個別リスク）を区別して評価・管理する概念。
將影響整個專案的總體不確定性（整體風險）與源於特定作業的因素（個別風險）加以區分並進行評估與管理的概念。
【問題】プロジェクトのリスク管理において、「全体リスク」と「個別リスク」に関する記述として、最も適切なものはどれか。
ア. 全体リスクは特定のタスクにのみ影響し、個別リスクはプロジェクト全体に影響を与える。
イ. 全体リスクはプロジェクト全体の不確実性の影響を表し、個別リスクは特定のアクティビティや事象に起因する。
ウ. 個別リスクの合計が必ず全体リスクと一致するため、全体リスクの評価は不要である。
エ. 全体リスクはプロジェクト完了後にのみ評価し、個別リスクは計画段階でのみ評価する。
正解：イ

解説：全体リスク（Overall Project Risk）は、すべての不確実性の源泉から生じるプロジェクト全体への影響を表します。一方、個別リスク（Individual Project Risk）は特定の特定可能な事象や状態に起因します。
 【題目】在專案風險管理中，關於「整體風險」與「個別風險」的描述，下列何者最恰當？
A. 整體風險僅影響特定任務，而個別風險影響整個專案。
B. 整體風險代表所有不確定性對專案整體的影響，個別風險則源於特定的活動或事件。
C. 個別風險的總和必然等於整體風險，因此不需要評估整體風險。
D. 整體風險僅在專案結束後評估，個別風險僅在規劃階段評估。
正確答案：B

解析：整體專案風險（Overall Project Risk）代表專案作為一個整體受到的不確定性影響；個別專案風險（Individual Project Risk）則是若發生會對一個或多個專案目標產生正面或負面影響的特定事件。
リスクの対象群
りすくのたいしょうぐん
風險管理領域（風險對象群）
Risk Target Group
リスクの特定、評価、対応計画の策定、監視・コントロールというリスク管理の一連のプロセス群。
包含風險辨識、評估、應對計畫制定以及監控管制等一連串專案風險管理過程的領域群。
【問題】プロジェクトにおけるリスク管理（リスクの対象群）のプロセス順序として、最も適切なものはどれか。
ア. リスクの特定 → リスクの評価（分析） → リスク対応の計画 → リスクの監視・コントロール
イ. リスク対応の計画 → リスクの特定 → リスクの評価 → リスクの監視
ウ. リスクの監視 → リスク対応の計画 → リスクの特定 → リスクの評価
エ. リスクの評価 → リスクの監視 → リスクの特定 → リスク対応の計画
正解：ア

解説：リスクマネジメントの基本的な手順は、まず潜在的なリスクを洗い出し（特定）、その影響や発生確率を分析（評価）し、対策を決定（対応計画）した上で、進行に合わせて効果を監視（コントロール）します。
 【題目】關於專案風險管理（風險對象群）的流程順序，下列何者最恰當？
A. 辨識風險 → 風險評估（分析） → 規劃風險應對 → 監控風險
B. 規劃風險應對 → 辨識風險 → 風險評估 → 監控風險
C. 監控風險 → 規劃風險應對 → 辨識風險 → 風險評估
D. 風險評估 → 監控風險 → 辨識風險 → 規劃風險應對
正確答案：A

解析：專案風險管理的標準程序為：辨識風險（Identify Risks）→ 進行定性/定量風險評估（Analyze Risks）→ 制定風險應對計畫（Plan Risk Responses）→ 持續監控與控制風險（Monitor Risks）。
