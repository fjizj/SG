結構化查詢語言
Structured Query Language
リレーショナルデータベースの操作（取得・追加・更新・削除）や管理を行うための標準的な言語。
用於對關聯式資料庫進行資料操作（檢索、新增、更新、刪除）與管理的標準化程式語言。
リレーショナルデータベースのデータを操作や定義するために使用される、国際標準化されたデータベース言語はどれか。
ア. HTML
イ. SQL
ウ. Python
エ. XML
正解：イ

解説：SQL（Structured Query Language）は、リレーショナルデータベース（RDB）のデータの操作（検索・挿入・更新・削除）や定義を行うための標準的なデータベース言語です。
 用於操作與定義關聯式資料庫資料的國際標準化資料庫語言是哪一個？
A. HTML
B. SQL
C. Python
D. XML
答案：B

解析：SQL（Structured Query Language）是用於對關聯式資料庫（RDB）進行資料操作（查詢、新增、更新、刪除）與定義的標準資料庫語言。
