通信プロトコル - 17語（シラバス4.1）

【IP位址與子網管理】
IPアドレス
あいぴーあどれす
IP位址
IP Address
インターネットやイントラネット上でデバイスを識別するための一意の番号であり、通信相手を特定する位置情報の役割を果たす。
在網際網路或企業內部網路中用於唯一識別裝置的專屬編號，扮演著明確標示通訊對象位置的角色。
過去問 (日本語) 考古題 (中文翻譯)
問題：IPアドレスに関する記述として、最も適切なものはどれか。
選択肢：
ア. ネットワークインターフェースカード（NIC）固有の物理アドレスである。
イ. インターネットなどのネットワークに接続された機器を識別するための論理アドレスである。
ウ. Webブラウザが閲覧対象のWebページを指定するためのURLのことである。
エ. 電子メールを送受信する際に個人を識別するためのアカウント名である。
正解：イ
解説：IPアドレスはネットワークに接続された端末を識別・特定するための論理的なアドレスです。物理アドレスはMACアドレスを指します。		 題目：關於 IP 位址的敘述，下列何者最恰當？
選項：
A. 網路介面卡（NIC）固有的實體位址。
B. 用於識別連接至網際網路等網路中之設備的邏輯位址。
C. Web 瀏覽器指定欲瀏覽網頁時所使用的 URL。
D. 電子郵件收發時用於識別個人的帳號名稱。
正確答案：(B)
解析：IP 位址是用於識別與定位網路上各項設備的邏輯位址。實體位址則是指 MAC 位址。
サブネットアドレス
さぶねっとあどれす
子網路位址
Subnet Address
大規模なネットワークを部門別や機能別に細分化し、効率的に管理・運用するためのネットワーク識別アドレスである。
將大型網路按部門或功能進行細分，以便更高效進行管理與通訊控制的子網路識別位址。
過去問 (日本語) 考古題 (中文翻譯)
問題：大規模ネットワークをサブネット化する主な目的として、適切なものはどれか。
選択肢：
ア. MACアドレスの重複を完全に防止するため
イ. ネットワークを細分化し、管理の効率化とトラフィックの制限を図るため
ウ. 通信速度を物理的に増加させるため
エ. 暗号化通信を強制的に適用するため
正解：イ
解説：サブネット化によりネットワークを小さな単位に分割することで、ブロードキャストドメインの制限やセキュリティ、管理の効率化が可能になります。		 題目：將大型網路進行劃分子網（Subnetting）的主要目的為何？
選項：
A. 完全防止 MAC 位址發生重複
B. 將網路進行細分，以提升管理效率並控制廣播流量
C. 物理性地大幅增加傳輸速度
D. 強制套用加密通訊協定
正確答案：(B)
解析：劃分子網可將大網路切分成小單位，達到限制廣播範疇、提升網路效能與便於維護管理的目的。
サブネットマスク
さぶねっとますく
子網路遮罩
Subnet Mask
IPアドレスのどの部分がネットワーク部で、どの部分がホスト部かを示すための識別ビット列である。
用於區分 IP 位址中何者代表網路位址部分、何者代表主機位址位元的識別位元列。
過去問 (日本語) 考古題 (中文翻譯)
問題：IPv4アドレス「192.168.10.15」でサブネットマスク「255.255.255.0」を使用する場合、ネットワークアドレスはどれか。
選択肢：
ア. 192.168.10.0
イ. 192.168.10.15
ウ. 192.168.10.255
エ. 255.255.255.0
正解：ア
解説：サブネットマスク「255.255.255.0」は上位24ビットがネットワーク部を示します。ホスト部を全ビット0にした「192.168.10.0」がネットワークアドレスとなります。		 題目：使用 IPv4 位址「192.168.10.15」與子網路遮罩「255.255.255.0」時，網路位址為何？
選項：
A. 192.168.10.0
B. 192.168.10.15
C. 192.168.10.255
D. 255.255.255.0
正確答案：(A)
解析：子網路遮罩「255.255.255.0」表示前 24 位元為網路部分，將主機部分位元全設為 0 後所得之「192.168.10.0」即為網路位址。
ルーティング
るーてぃんぐ
路由選擇
Routing
パケットが送信元から目的地まで最適かつ正確に到達するための経路を決定し、転送するプロセスである。
在網路通訊中，選擇並判定讓封包從來源端有效率地傳送至目的地最佳路徑的控制機制。
過去問 (日本語) 考古題 (中文翻譯)
問題：OSI参照モデルのネットワーク層で動作し、IPアドレスをもとに最適な経路を選択してパケットを転送する機器はどれか。
選択肢：
ア. リピーター
イ. スイッチングハブ
ウ. ルーター
エ. ゲートウェイ
正解：ウ
解説：ルーターはルーティングテーブルを参照し、宛先IPアドレスに基づいてパケットの最適な経路を決定（ルーティング）します。		 題目：運作於 OSI 參考模型的網路層，根據 IP 位址選擇最佳路徑並轉發封包的設備為何？
選項：
A. 中繼器 (Repeater)
B. 交換式集線器 (Switching Hub)
C. 路由器 (Router)
D. 閘道器 (Gateway)
正確答案：(C)
解析：路由器參照路由表，根據目的 IP 位址執行路徑選擇（Routing）並進行封包轉發。
【IP通訊協定版本】
IPv4
あいぴーぶいふぉー
IPv4 通訊協定
Internet Protocol version 4
32ビットのアドレス空間（約42億個）を持ち、ドット区切りの10進数で表現される従来標準のIPプロトコル。
採用 32 位元（約 42 億個）位址空間，並以點分十進位格式標示的網際網路基本協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：IPv4アドレスのビット長として、正しいものはどれか。
選択肢：
ア. 16ビット
イ. 32ビット
ウ. 64ビット
エ. 128ビット
正解：イ
解説：IPv4アドレスは32ビットの数値で構成され、8ビットごとにドットで区切って10進数表示します。		 題目：下列何者為 IPv4 位址的位元長度？
選項：
A. 16 位元
B. 32 位元
C. 64 位元
D. 128 位元
正確答案：(B)
解析：IPv4 位址由 32 位元的數值組成，每 8 位元一組以點分隔並轉為十進位標示。
IPv6
あいぴーぶいしっくす
IPv6 通訊協定
Internet Protocol version 6
IPv4のアドレス枯渇に対応するため設計された、128ビットの膨大なアドレス空間を持つ次世代プロトコル。
為解決 IPv4 位址枯竭問題而設計，擁有 128 位元龐大位址空間的新一代網際網路協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：IPv6に関する記述として、適切なものはどれか。
選択肢：
ア. アドレス空間は32ビットで構成される。
イ. アドレス表記には16進数が使用され、128ビットの長さを持つ。
ウ. IPv4とアドレス長が同じであり互換性がある。
エ. ドットで区切られた4つの10進数で表記される。
正解：イ
解説：IPv6は128ビットの長さを持ち、16ビットごとにコロンで区切られた16進数で表記されます。		 題目：關於 IPv6 的敘述，下列何者正確？
選項：
A. 位址空間由 32 位元組成。
B. 位址採用十六進位標示，長度為 128 位元。
C. 與 IPv4 長度相同且具備完全相容性。
D. 由以點分隔的 4 個十進位數字組成。
正確答案：(B)
解析：IPv6 具備 128 位元的長度，每 16 位元以冒號分隔並以十六進位格式表示。
【區域網路與硬體定址】
MACアドレス
まっくあどれす
MAC 位址 / 實體位址
Media Access Control Address
ネットワーク機器のNICに製造時に割り当てられる48ビットの物理アドレスで、ローカル通信で機器を識別する。
出廠時刻錄於網路卡（NIC）上的 48 位元實體位址，用於區域網路內部的裝置識別。
過去問 (日本語) 考古題 (中文翻譯)
問題：MACアドレスの説明として、適切なものはどれか。
選択肢：
ア. ネットワーク層で通信相手を特定するために使用される論理アドレス
イ. ネットワーク機器の製造時にNICへ書き込まれる48ビットの物理アドレス
ウ. DHCPサーバによって接続時に動的に割り当てられるアドレス
エ. Webサーバ上のリソースを一意に指定するための識別子
正解：イ
解説：MACアドレスはデータリンク層で使用される48ビットの物理アドレスで、前半24ビットはベンダーコード、後半24ビットは固有番号です。		 題目：下列關於 MAC 位址的說明，何者正確？
選項：
A. 於網路層用於指定通訊對象之邏輯位址
B. 於網路設備製造時燒錄至 NIC 的 48 位元實體位址
C. 連線時由 DHCP 伺服器動態分配的位址
D. 用於唯一指定 Web 伺服器資源的識別碼
正確答案：(B)
解析：MAC 位址是用於資料鏈結層的 48 位元實體位址，前 24 位元為廠商代碼，後 24 位元為設備獨有編號。
Ethernet
いーさねっと
乙太網路
Ethernet
有線LANで最も広く利用されている通信標準であり、データを「フレーム」という単位で送受信する技術。
最廣泛使用的有線區域網路（LAN）標準通訊規格，以「訊框（Frame）」為基本單位進行資料傳輸。
過去問 (日本語) 考古題 (中文翻譯)
問題：有線LAN規格であるイーサネット（Ethernet）で伝統的に使われている媒体アクセス制御方式はどれか。
選択肢：
ア. CSMA/CD
イ. CSMA/CA
ウ. トークンパッシング
エ. TDMA
正解：ア
解説：有線LANのイーサネットでは衝突検出を行うCSMA/CD方式が用いられます。無線LANでは衝突回避のCSMA/CA方式が使われます。		 題目：有線 LAN 規格乙太網路（Ethernet）傳統採用的通訊介面存取控制方式為何？
選項：
A. CSMA/CD
B. CSMA/CA
C. Token Passing (記號傳遞)
D. TDMA
正確答案：(A)
解析：有線乙太網路採用碰撞偵測機制 CSMA/CD；而無線 LAN 則採用碰撞避免機制 CSMA/CA。
【傳輸層與網路自動化服務】
ポート番号
ぽーとばんごう
連接埠號碼
Port Number
同一端末上で動作する複数のアプリケーションや通信サービスを識別するための0〜65535の識別番号である。
用於在同一台裝置上區分不同應用程式或服務通訊管道的 0 至 65535 號通訊埠編號。
過去問 (日本語) 考古題 (中文翻譯)
問題：TCP/IP通信において、トランスポート層で特定のアプリケーションプログラムを識別するために使用される番号はどれか。
選択肢：
ア. IPアドレス
イ. MACアドレス
ウ. ポート番号
エ. ホストID
正解：ウ
解説：IPアドレスが「通信相手のコンピュータ」を特定するのに対し、ポート番号は「そのコンピュータ内のどのアプリケーションか」を特定します。		 題目：在 TCP/IP 通訊中，傳輸層用於識別特定應用程式的編號為何？
選項：
A. IP 位址
B. MAC 位址
C. 連接埠號碼 (Port Number)
D. 主機 ID
正確答案：(C)
解析：IP 位址用於指定「網路上的電腦」，而連接埠號碼則是用於指定「該電腦內部的特定應用程式」。
DHCP
でぃーえいちしーぴー
動態主機設定協定
Dynamic Host Configuration Protocol
ネットワークに接続された端末へIPアドレスなどの設定情報を自動的に割り当てるプロトコルである。
自動為連接至網路的用戶端裝置發放 IP 位址及相關網路組態設定的協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：PCをLANに接続した際、IPアドレスやサブネットマスク、デフォルトゲートウェイの情報を自動取得するために利用されるプロトコルはどれか。
選択肢：
ア. DNS
イ. DHCP
ウ. ARP
エ. NTP
正解：イ
解説：DHCP（Dynamic Host Configuration Protocol）は、クライアントに対してIPアドレス等のネットワーク設定を自動的に配布するプロトコルです。		 題目：將電腦接入 LAN 時，用於自動取得 IP 位址、子網路遮罩與預設閘道等設定資訊的協定為何？
選項：
A. DNS
B. DHCP
C. ARP
D. NTP
正確答案：(B)
解析：DHCP（動態主機設定協定）負責向用戶端自動分發 IP 位址等網路設定參數。
【應用層通訊協定】
HTTP
えいちてぃてぃぴー
超文字傳輸協定
Hypertext Transfer Protocol
WebブラウザとWebサーバ間で、HTMLテキストや画像などのデータを送受信するためのリクエスト・レスポンス型プロトコル。
用於 Web 瀏覽器與伺服器之間傳送 HTML 與圖片等 Web 內容，採請求-回應機制的通訊協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：WebブラウザとWebサーバの間で、Webページデータの送受信に用いられるプロトコルはどれか。
選択肢：
ア. FTP
イ. HTTP
ウ. SMTP
エ. POP3
正解：イ
解説：HTTP（Hypertext Transfer Protocol）はWebページ（HTML等）を取得するためのプロトコルです。		 題目：在 Web 瀏覽器與 Web 伺服器之間傳送網頁資料時所採用的協定為何？
選項：
A. FTP
B. HTTP
C. SMTP
D. POP3
正確答案：(B)
解析：HTTP（超文字傳輸協定）專門用於擷取與傳送包含 HTML 內容之 Web 頁面資料。
SMTP
えすえむてぃぴー
簡單郵件傳輸協定
Simple Mail Transfer Protocol
電子メールをクライアントから送信したり、メールサーバ同士で転送したりする際に使用されるプロトコル。
用於將電子郵件從用戶端發送，或在各郵件伺服器之間進行轉送傳輸的標準協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：電子メールシステムにおいて、メールの「送信」および「サーバ間転送」に使われるプロトコルはどれか。
選択肢：
ア. POP3
イ. IMAP
ウ. SMTP
エ. DHCP
正解：ウ
解説：メール送信・転送にはSMTPが使われます。POP3やIMAPはメール受信用のプロトコルです。		 題目：於電子郵件系統中，專用於郵件「發送」與「伺服器間轉發」的通訊協定為何？
選項：
A. POP3
B. IMAP
C. SMTP
D. DHCP
正確答案：(C)
解析：郵件的發送與轉發均使用 SMTP 協定；POP3 與 IMAP 則為收取郵件所使用的協定。
POP3
ぽっぷすりー
郵局協定第三版
Post Office Protocol version 3
メールサーバからメールを端末にダウンロードし、ローカル環境で保存・管理・閲覧するための受信プロトコル。
將電子郵件從伺服器下載至本機裝置儲存，以便進行離線閱讀與管理的收件通訊協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：電子メール受信プロトコルであるPOP3の特徴として、適切なものはどれか。
選択肢：
ア. メールを端末にダウンロードしてローカルで管理する。
イ. メールを常にサーバ上で管理し、複数端末での未読状態を同期する。
ウ. Webブラウザ上でメールの送受信を行う。
エ. メール送信時の暗号化を行う。
正解：ア
解説：POP3はメールをローカル端末にダウンロードして管理します。サーバ側で一括管理して複数端末同期を行うのはIMAPです。		 題目：關於電子郵件收件協定 POP3 的特性，下列何者正確？
選項：
A. 將郵件下載至本機裝置並於本機端進行管理。
B. 郵件常駐於伺服器管理，並同步多台裝置間的未讀狀態。
C. 直接於 Web 瀏覽器上執行郵件的收發。
D. 負責郵件發送時的內容加密。
正確答案：(A)
解析：POP3 會將郵件下載至本機端進行管理。若要在伺服器端一併託管並實現跨裝置同步則為 IMAP。
IMAP
あいまっぷ
網際網路訊息存取協定
Internet Message Access Protocol
メールをサーバ上で管理し、複数デバイス間で未読・既読・フォルダ状態をリアルタイム同期できる受信プロトコル。
將電子郵件保留於伺服器上管理，可實現跨多台裝置即時同步已讀/未讀狀態與資料夾的收件協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：POP3と比較したときのIMAPの主な利点として、適切なものはどれか。
選択肢：
ア. メールをサーバに移動させず端末内にのみ保存できる点
イ. 複数の端末からアクセスしても、サーバ上で未読・既読やフォルダ状態が同期される点
ウ. 送信用のサーバを別途用意する必要がない点
エ. インターネットに接続せずに新しいメールを受信できる点
正解：イ
解説：IMAPはメール本体やフォルダ構成をサーバ上で管理するため、PCやスマートフォンなど異なる端末からアクセスしても同じ状態を保てます。		 題目：與 POP3 相比，IMAP 通訊協定的主要優勢為何？
選項：
A. 不將郵件移至伺服器，僅儲存於單一裝置內部
B. 由多台裝置登入存取時，伺服器上的未讀/已讀與資料夾狀態皆能保持同步
C. 不需要另外準備發信用伺服器
D. 無須連線至網際網路即可接收新郵件
正確答案：(B)
解析：IMAP 直接於伺服器託管郵件主體與資料夾結構，因此無論使用電腦或手機登入，均可同步最新的資料狀態。
FTP
えふてぃーぴー
檔案傳輸協定
File Transfer Protocol
ネットワークを介してクライアントとサーバ間でファイルをアップロード・ダウンロードするための専用プロトコル。
用於在用戶端與伺服器之間透過網路進行檔案上傳與下載傳送的專用協定。
過去問 (日本語) 考古題 (中文翻譯)
問題：ネットワークを介してクライアントとサーバ間でファイルを転送するために用いられるアプリケーション層プロトコルはどれか。
選択肢：
ア. FTP
イ. DHCP
ウ. NTP
エ. ARP
正解：ア
解説：FTP（File Transfer Protocol）はファイル転送専用のプロトコルです。セキュリティを高めた方式としてSFTPやFTPSが存在します。		 題目：用於在用戶端與伺服器之間透過網路傳輸檔案的應用層通訊協定為何？
選項：
A. FTP
B. DHCP
C. NTP
D. ARP
正確答案：(A)
解析：FTP（檔案傳輸協定）為專用於檔案傳輸的通訊協定。升級安全性的變體包括 SFTP 與 FTPS。
【無線通訊與 Wi-Fi 規格】
IEEE802.11a/b/g/n/ac/ax
あいとりぷるいーはちまるにてんいちいち・えー/びー/じー/えぬ/えーしー/えーえっくす
IEEE 802.11 無線網路標準群
IEEE 802.11 Standards
米国IEEEが策定した無線LAN技術の標準規格群であり、周波数帯域や最高伝送速度が世代ごとに規定されている。
由 IEEE 制定之無線區域網路（Wi-Fi）標準規格群，詳細規定了各世代之通訊頻段與傳輸速率。
過去問 (日本語) 考古題 (中文翻譯)
問題：無線LAN規格であるIEEE 802.11nに関する記述として、適切なものはどれか。
選択肢：
ア. 2.4GHz帯と5GHz帯の両方の周波数帯に対応している。
イ. 5GHz帯のみを使用し、2.4GHz帯には対応していない。
ウ. 赤外線を用いて近距離通信を行う。
エ. 最大伝送速度は54Mbpsにとどまる。
正解：ア
解説：802.11n（Wi-Fi 4）は2.4GHz帯と5GHz帯の両方に対応し、MIMO（Multiple-Input Multiple-Output）技術の採用により高速化を実現しました。		 題目：關於無線 LAN 規格 IEEE 802.11n 的敘述，下列何者正確？
選項：
A. 支援 2.4GHz 與 5GHz 兩種通訊頻段。
B. 僅支援 5GHz 頻段，無法使用 2.4GHz 頻段。
C. 採用紅外線執行短距離資料傳輸。
D. 最大傳輸速率僅限於 54Mbps。
正確答案：(A)
解析：802.11n (Wi-Fi 4) 可同時支援 2.4GHz 與 5GHz 雙頻段，並引進 MIMO 天線技術大幅提升傳輸速度。
Wi-Fi4/5/6/6E
わいふぁい4/5/6/6E
Wi-Fi 世代標示規格
Wi-Fi 4/5/6/6E
IEEE 802.11規格の世代を分かりやすく表記したブランド名称であり、Wi-Fi 6Eでは新たに6GHz帯も利用可能。
為方便使用者識別將 802.11 規格簡化之世代品牌名稱，其中 6E 更導入了全新 6GHz 通訊頻段。
過去問 (日本語) 考古題 (中文翻譯)
問題：Wi-Fi 6（IEEE 802.11ax）の主な特徴として、最も適切なものはどれか。
選択肢：
ア. 従来規格より最高速度が向上しただけでなく、OFDMA等により多数の端末が同時接続する環境でも通信効率が高い。
イ. 2.4GHz帯のみを使用する低速低消費電力専用規格である。
ウ. 通信距離が10メートルに限定される近距離規格である。
エ. 有線LANのケーブル接続を代替するための規格である。
正解：ア
解説：Wi-Fi 6（802.11ax）は通信速度の向上（最大9.6Gbps）に加え、OFDMA技術により高密度環境（多数機器接続）での混雑緩和が図られています。		 題目：關於 Wi-Fi 6 (IEEE 802.11ax) 的主要特徵，下列何者最恰當？
選項：
A. 不僅最高速率大幅提升，透過 OFDMA 等技術，在大量裝置同時連線的環境中亦具高傳輸效率。
B. 僅使用 2.4GHz 頻段，為低速低耗電專用之規格。
C. 通訊距離嚴格限制於 10 公尺以內之近距離規格。
D. 為替代有線 LAN 實體線路連接而設計之規格。
正確答案：(A)
解析：Wi-Fi 6 (802.11ax) 除了提升傳輸速率（最高 9.6Gbps）外，更利用 OFDMA 技術有效改善高密度多設備連結下的網路壅塞。
