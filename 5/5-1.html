社内LANや家庭内ネットワークなどの閉じた組織内で自由に割り当てて使用できる、インターネット上では直接使用できないIPアドレスはどれか。
ア. プライベートIPアドレス
イ. グローバルIPアドレス
ウ. マルチキャストアドレス
エ. ブロードキャストアドレス
正解：ア

解説：プライベートIPアドレス（ローカルIPアドレス）は、同一LAN内で一意であれば自由に使える内部ネットワーク専用アドレスです。
 供企業內網或家庭網路等封閉內部組織自由分配使用，無法在網際網路上直接路由的 IP 位址是哪一個？
A. 私有 IP 位址
B. 公用 IP 位址
C. 多播位址
D. 廣播位址
答案：A

解析：私有 IP 位址（Private IP Address，如 192.168.x.x）專供內部區域網路使用，需搭配 NAT 技術才能連接外部網際網路。
ドメイン

網域名稱
Domain
数字のIPアドレスを人間が識別しやすい文字列（例: example.com）で表現したインターネット上の住所。
將由數字組成的 IP 位址轉換為人類易於記憶的文字字串（如 example.com），作為網路上的識別名稱。
インターネット上のコンピュータやWebサイトの場所を人間が理解しやすい文字列で表した識別名称（例：example.co.jp）はどれか。
ア. ドメイン名
イ. IPアドレス
ウ. MACアドレス
エ. ポート番号
正解：ア

解説：ドメイン名（Domain Name）は、数字のみで表現されるIPアドレスを人間が覚えやすい文字表記に変換したインターネット上の名称です。
 將網際網路上的電腦或網站位置，以人類易於理解的文字字串（例如 example.co.jp）表示的識別名稱是哪一個？
A. 網域名稱
B. IP 位址
C. MAC 位址
D. 連接埠號（Port Number）
答案：A

解析：網域名稱（Domain Name）為 IP 位址的文字別名，方便人類閱讀、記憶與進行品牌推廣。
DNS
でぃーえぬえす
網域名稱系統
Domain Name System
人間が読みやすいドメイン名と、コンピュータが扱うIPアドレスを相互に変換（名前解決）する仕組み。
負責將人類易讀的網域名稱與電腦處理所需的 IP 位址互相轉換（名稱解析）的網路系統。
「example.com」のようなドメイン名から「192.0.2.1」のようなIPアドレスを検索・変換する（名前解決を行う）システムはどれか。
ア. DNS
イ. DHCP
ウ. NTP
エ. SNMP
正解：ア

解説：DNS（Domain Name System）は、ドメイン名とIPアドレスの対応関係を管理し、相互に変換する名前解決サーバーシステムです。
 將如「example.com」的網域名稱查詢並轉換為如「192.0.2.1」的 IP 位址（執行名稱解析）的系統是哪一個？
A. DNS
B. DHCP
C. NTP
D. SNMP
答案：A

解析：DNS（Domain Name System）執行名稱解析（Name Resolution）服務，讓使用者不必輸入複雜的數字 IP 即可存取網站。
RADIUS
らでぃうす
遠端用戶撥號認證服務
Remote Authentication Dial-In User Service
ネットワーク接続時のユーザー認証、権限付与、利用履歴記録（AAA）を一元管理するプロトコル。
用於集中管理使用者接入網路時的身份認證、授權與存取紀錄（AAA）的通訊協定。
ネットワークアクセスにおけるユーザー認証、承認、利用記録（AAA機能）をサーバで一元的に管理するためのプロトコルはどれか。
ア. RADIUS
イ. SNMP
ウ. SMTP
エ. LDAP
正解：ア

解説：RADIUS（Remote Authentication Dial-In User Service）は、ダイヤルアップ接続や無線LAN、VPNなどにおけるユーザー認証を一元管理する標準プロトコルです。
 在網路存取控制中，於伺服器端集中管理使用者身份認證、授權與使用紀錄（AAA 功能）的協定是哪一個？
A. RADIUS
B. SNMP
C. SMTP
D. LDAP
答案：A

解析：RADIUS 協定廣泛應用於 Wi-Fi 企業認證及 VPN 存取控制，集中處理身份認證（Authentication）、授權（Authorization）與計費紀錄（Accounting）。
